# 🔗 I²C 通信协议完整技术手册

> [!INFO] 笔记概览
> - **协议定位**：两线制（SDA/SCL）、半双工、同步、开漏 + 上拉的多主总线，靠 7/10 位地址寻址，支持 Clock Stretching 与线与仲裁。
> - **内容范围**：物理电气 · 帧格式（7/10 位地址）· START/STOP/ACK 时序 · 速度模式 · 线与仲裁 · Clock Stretching
> - **推荐路径**：§1 物理层 → §2 帧格式 → §3 控制时序 → §4 速度模式 → §5 仲裁 → §6 Clock Stretching

## 🔌 1. 组成与物理特性

| 信号 | 全称 | 方向 | 说明 |
| :--: | :--- | :--: | :--- |
| **SDA** | Serial Data | 双向 | 串行数据线，主机与从机的数据读写、应答均通过此线 |
| **SCL** | Serial Clock | 主机驱动 | 串行时钟线，控制通信速率与采样同步 |

- **通信模式**：半双工（Half-Duplex）同步串行通信。
- **硬件电气**：SDA 与 SCL 均为**开漏输出（Open-Drain）**，总线上必须外接上拉电阻（典型 2.2 kΩ ~ 4.7 kΩ），空闲状态均为高电平。

> [!NOTE] 为什么用开漏 + 上拉
> 开漏结构允许多设备"线与"（Wired-AND）共享同一总线：任一设备拉低即为低，全部释放才为高。这既是仲裁（§5）也是 Clock Stretching（§6）的物理基础。上拉阻值需按总线电容与速率权衡（越大越省电但上升沿越慢）。

## 📦 2. I²C 帧格式

### 2.1 7-bit 地址模式（最常用）

寻址阶段由 **1 个字节（8 位）** 构成，后跟 1 个应答位：

| 组成 | 位分布 | 说明 |
| :--- | :--- | :--- |
| 地址位 | 第 1 字节高 7 位（`Bit7~Bit1`） | 从机地址 |
| 读写位 (R/W) | 第 1 字节最低位（`Bit0`） | `0`=写入(Write)，`1`=读取(Read) |
| 数据位 | 后续字节（每单元 8-bit） | 有效载荷 |
| 应答位 (ACK/NACK) | 每 8-bit 后 1 位 | 接收方拉低 SDA 产生应答 |

```text
┌─────────────────────── 第 1 字节 ───────────────────────┐ ┌─ACK─┐
│ A6  A5  A4  A3  A2  A1  A0 │ R/W │                     │ │     │
└─────────── 7 位地址 ───────┴─────┘                      │ └─────┘
                                                    接收方拉低=ACK
```

### 2.2 10-bit 地址模式

10 位地址无法在单字节容纳，采用**双字节组合寻址**：

| 传输顺序 | 组成内容 | 位分布 (MSB → LSB) | 响应 | 说明 |
| :--- | :--- | :--- | :--: | :--- |
| **第 1 字节** | 固定前缀(5) + 地址高位(2) + R/W(1) | `1 1 1 1 0` + `A9 A8` + `R/W` | ACK | 通知进入 10-bit 寻址，匹配高位 |
| **第 2 字节** | 地址剩余低位(8) | `A7 A6 A5 A4 A3 A2 A1 A0` | ACK | 匹配完整 10-bit 地址 |
| **后续字节** | 传输数据 | 数据载荷（每单元 8-bit） | ACK/NACK | 进入标准数据读写 |

## ⏱️ 3. 关键控制时序

### 3.1 START / STOP / REPEATED START

```text
START (S)：SCL 高电平期间，SDA 由高→低（下降沿）
STOP  (P)：SCL 高电平期间，SDA 由低→高（上升沿）
REPEATED START (Sr)：与 START 相同，用于读写方向切换而不释放总线
```

```text
        SCL 高时 SDA 变化 = 控制信号
SDA  ‾‾\____  (START)          SDA  ____/‾‾  (STOP)
SCL  ‾‾‾‾‾‾‾                   SCL  ‾‾‾‾‾‾‾
```

> [!NOTE] 数据有效性
> - **采样阶段**：SCL 为**高**电平时，SDA 必须保持稳定，供接收端读取；
> - **切换阶段**：只有 SCL 为**低**电平时，SDA 才允许改变，准备下一位。
> - 简言之：**SCL 低时把 1 bit 数据放上 SDA，SCL 高时对方读取该 bit。** 正因 SCL 高时 SDA 不允许变化，START/STOP 才用"SCL 高时 SDA 跳变"来专门表示。

### 3.2 应答机制（ACK / NACK）

| 信号 | 电平 | 含义 |
| :--: | :--: | :--- |
| **ACK** | 0 | 第 9 个时钟周期，接收端**拉低 SDA** 表示成功接收 |
| **NACK** | 1 | 第 9 个时钟周期，接收端**释放 SDA**（上拉拉高），表示无应答/结束 |

## 🚀 4. 速度模式

| 模式 | 速率 | 说明 |
| :--- | :--- | :--- |
| **Standard-mode (SM)** | ≤ 100 kbit/s | 标准模式 |
| **Fast-mode (FM)** | ≤ 400 kbit/s | 快速模式，最常用 |
| **Fast-mode Plus (FM+)** | ≤ 1 Mbit/s | 需更强驱动、更低上拉 |
| **High-speed (HS)** | ≤ 3.4 Mbit/s | 需主码 + 电流源上拉 |

## ⚖️ 5. I²C 仲裁机制（Arbitration）

### 5.1 硬件物理基础："线与"（Wired-AND）

- SDA 和 SCL 均为**开漏**结构，由外部上拉电阻拉高；
- 任一设备输出低（0），总线即为低（0）；
- 只有所有设备都释放（高阻），总线才是高（1）；
- **规则核心**：低电平（0）对高电平（1）具有**绝对覆盖性**（0 压制 1）。

### 5.2 仲裁过程与时序规则

```text
边发边读（回读检测）：每个主机发 1 bit 时，在 SCL 高采样窗口同时读 SDA 实际电平
逐位比较（从 MSB 开始）：
  发 0 读 0 → 继续          发 1 读 1 → 继续
  发 1 读 0 → 有他人抢占总线 → 判定自己仲裁失败（Arbitration Lost）
```

### 5.3 仲裁范围

仲裁贯穿整个传输，不仅发生在地址阶段：

1. **地址阶段**：比较 7-bit / 10-bit 从机地址；
2. **读写位阶段**：访问同一从机时，发写指令（0）的主机优先于发读指令（1）的主机；
3. **数据阶段**：两主机对同一从机执行相同读写时，持续比较数据字节，直到首次出现差异。

### 5.4 仲裁结束与后续行为

> [!TIP] 获胜方无感知
> 由于仲裁过程没有任何电平被破坏（0 保持为 0），**胜出方完全感知不到竞争的存在**，数据无损、时序无缝继续。

失败方（Loser）必须：

- 在发现不一致的**当前 bit 周期内立即关闭 SDA 输出驱动**（释放总线），**不能产生 STOP**，防止干扰获胜方；
- 切换为从机/监听模式，继续接收总线时钟与数据（防获胜方目标恰好是自己）；
- 等总线出现 STOP 变空闲后，再择机重试本次通信。

## ⏸️ 6. Clock Stretching（时钟拉伸）

I²C 从机独有的**硬件级背压**机制：当从机来不及处理时，可把 **SCL 拉低**暂停时钟，迫使主机等待。

```text
Master                         Slave
  │──── SCL/SDA ────────────────►│
  │                          Buffer 快满 / 未就绪
  │◄──── SCL 拉低（暂停时钟）─────│
  │                          从机处理数据
  │◄──── 释放 SCL ────────────────│
  │──── 继续 SCL ────────────────►│
```

> [!NOTE] Clock Stretching 的边界
> 它相当于硬件级背压，但只能暂停"当前正在进行的事务"，**不能禁止 Master 以后发起新事务**——下一笔事务仍由 Master 决定。这一机制在流控体系中的定位见 [[DMA、Buffer 与流量控制]] §8.5。

> [!WARNING] 主机侧注意事项
> 并非所有主机都支持 Clock Stretching。若从机会拉伸时钟，主机控制器必须启用相应支持，否则会在从机未就绪时强行推进，导致数据错误。

## ✅ 落地校验清单（Checklist）

> [!SUCCESS] I²C 链路调试前必过
> - [ ] **上拉电阻**：SDA/SCL 各接 2.2k~4.7kΩ（按总线电容与速率调整）
> - [ ] **地址模式**：确认 7-bit / 10-bit，注意有些库用"8 位地址"（含 R/W，需左移）
> - [ ] **速率匹配**：主机速率不超过最慢从机上限（SM/FM/FM+/HS）
> - [ ] **START/STOP**：SCL 高时 SDA 跳变表示控制信号，数据切换只在 SCL 低时
> - [ ] **ACK 检查**：每字节后检查 ACK，NACK 时正确终止或重试
> - [ ] **多主仲裁**：失败方立即释放 SDA、不发 STOP、转监听
> - [ ] **Clock Stretching**：确认主机支持；从机拉伸不超时
> - [ ] **总线锁死恢复**：从机异常拉低 SDA 时，主机发 9 个 SCL 脉冲 + STOP 解锁
