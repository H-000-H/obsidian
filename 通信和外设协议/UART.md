# UART 通信协议技术总结

## 1. 组成与物理特性

### 1.1 通信方式

- **定义**：UART（Universal Asynchronous Receiver/Transmitter，通用异步收发器）。
- **传输方式**：异步串行通信。
- **双工模式**：通常采用全双工通信（可同时收发）。
- **时钟机制**：无单独的时钟线（CLK），收发双方依赖预先约定的**波特率**配合本地时钟进行自同步。
- **基础信号线**：
    - **TX（Transmit）**：数据发送通道。
    - **RX（Receive）**：数据接收通道。
    - **GND（Ground）**：信号参考地。双方必须共地以提供统一的参考电平。

### 1.2 物理接线关系
收发双方的 TX 与 RX 必须**交叉连接**，GND 直连：
Plaintext
```
MCU / 发送端                     PC / 接收端
┌─────────┐                     ┌─────────┐
│      TX ├────────────────────►│ RX      │
│      RX │◄────────────────────┤ TX      │
│     GND ├─────────────────────┤ GND     │
└─────────┘                     └─────────┘
```
> **注**：若启用硬件流控，RTS（Request to Send）与 CTS（Clear to Send）引脚同样需要交叉互连。
> 

### 1.3 协议层与物理电气标准解耦
UART 仅规定数据链路层的帧格式与时序，不绑定特定的物理电平。根据传输距离与抗干扰要求，可配合不同的收发芯片接入不同电气总线：

  

| **接口标准**       | **逻辑 0 电平**                        | **逻辑 1 电平**                              | **电气形态**      | **传输距离与特点**                                        |
| -------------- | ---------------------------------- | ---------------------------------------- | ------------- | -------------------------------------------------- |
| **TTL / CMOS** | $0\text{ V}$（或 $\le 0.8\text{ V}$） | $V_{CC}$（通常 $3.3\text{ V} / 5\text{ V}$） | 单端（相对系统地）     | 板级/近距离调试（$< 30\text{ cm}$）                         |
| **RS-232**     | $+3\text{ V} \sim +15\text{ V}$    | $-3\text{ V} \sim -15\text{ V}$（负逻辑）     | 单端（相对信号地）     | 短距设备互连（$< 15\text{ m}$，通常 $\le 115.2\text{ kbps}$） |
| **RS-485**     | $V_A - V_B < -200\text{ mV}$       | $V_A - V_B > +200\text{ mV}$             | 差分信号对（A/B 双线） | 远距离工业现场总线（可达 $1200\text{ m}$，支持多节点挂载）              |
## 2. 帧格式与传输时序
### 2.1 时序图
总线在空闲（Idle）状态下保持**高电平（Mark 状态）**。传输单个字符的完整时序如下：

Plaintext

```
       Idle ──┐      ┌─── D0 ─── D1 ─── D2 ─── D3 ─── D4 ─── D5 ─── D6 ─── D7 ─── [Parity] ───┐ ┌── Idle
              │Start │                                                                  │ │Stop
              └──────┘                                                                  └───┘
Bit 状态:       逻辑 0                LSB 首发，MSB 尾发 (常用 5~9 bit)                    可选    逻辑 1 (1/1.5/2 bit)
```
### 2.2 字段构成

1. **空闲状态（Idle）**：持续高电平（逻辑 1）。
2. **起始位（Start Bit）**：固定 1 bit 低电平（逻辑 0），作为同步前导沿，用于唤醒接收器并重置内部位采样定时器。
3. **数据位（Data Bits）**：有效载荷通常为 8 bit（硬件支持 5～9 bit），传输规则默认遵循 **LSB first**（低位在前，高位在后）。
4. **校验位（Parity Bit）**：可选配置（0 或 1 bit），用于单字节基础差错检测。
5. **停止位（Stop Bit）**：固定高电平（逻辑 1），可选 1、1.5 或 2 bit。使线路恢复高电平，并为接收端提供缓冲处理间隙。
## 3. 校验逻辑与容错机制

### 3.1 奇偶校验生成规则

奇偶校验通过统计数据位中“1”的个数来确定校验位电平：

|**校验类型**|**代号**|**判定规则**|**示例（数据 0x53 = 0101 0011b，含 4 个“1”）**|
|---|---|---|---|
|**无校验 (None)**|**N**|帧中不包含校验位。|总开销最小，常用于调试与高层带校验的协议。|
|**偶校验 (Even)**|**E**|数据位与校验位中“1”的总个数为**偶数**。|4 个“1”已为偶数 $\rightarrow$ 校验位置 **0**。|
|**奇校验 (Odd)**|**O**|数据位与校验位中“1”的总个数为**奇数**。|4 个“1”为偶数 $\rightarrow$ 校验位置 **1**（凑成 5 个）。|
|**标记校验 (Mark)**|**M**|校验位恒置为逻辑 **1**。|固定为 1（常用于多机主从通信的地址帧标记）。|
|**空白校验 (Space)**|**S**|校验位恒置为逻辑 **0**。|固定为 0（常用于多机主从通信的数据帧标记）。|

> **局限性**：奇偶校验仅能发现**奇数个 bit 翻转**（如 1、3 个 bit 突发错误）。若发生偶数个 bit 翻转，校验仍会显示正常。高可靠场景需在应用层追加 CRC-16/32 或 CheckSum。
> 
>   

### 3.2 接收采样与抗干扰机制（Over-sampling）

由于没有共享时钟线，接收端采用本地高频倍频时钟（通常为波特率的 **8x 或 16x**）进行动态重采样：
- **有效边沿捕获**：检测到 RX 出现下降沿后，延迟半个 bit 时间（如 16x 采样的第 7/8/9 个时钟脉冲）复测电平，若仍为低电平则确认起始位有效，过滤瞬态毛刺。
- **多数表决判决**：在每个 bit 周期的中间区域连续采集 3 个样本，采取“3 选 2”表决逻辑确定该位最终电平，避开边沿建立过程中的抖动。
### 3.3 硬件状态错误类型
- **PE（Parity Error，奇偶校验错误）**：硬件统计的数据位“1”个数与预设规则不符。
- **FE（Framing Error，帧错误）**：在预设停止位的时间窗内未检测到高电平（主要由**波特率不匹配**或**时钟严重漂移**引起）。
- **OE（Overrun Error，溢出错误）**：移位寄存器已接收满，但 CPU/DMA 未及时读走 RDR 缓冲寄存器的数据，导致旧数据被覆写。
- **NE / NF（Noise Error，噪声标志）**：单 bit 窗口内的多次过采样值不一致，指示线路存在高频电磁干扰。

配置表示法通式为：**数据位 + 校验方式 + 停止位**。

## 5. 波特率、数据吞吐量与时钟误差模型
### 5.1 理论吞吐率计算
在常规 NRZ 编码下，$1\text{ Baud} = 1\text{ bit/s}$。
$$\text{有效字符吞吐率 (Byte/s)} = \frac{\text{波特率}}{\text{每帧总 bit 数}}$$
以常用波特率及常见配置测算：

|**波特率 (Baud)**|**8N1 理论吞吐量 (Byte/s)**|**8E1 / 8O1 / 8N2 理论吞吐量 (Byte/s)**|
|---|---|---|
|**9,600**|$960\text{ B/s}$（约 $0.94\text{ KB/s}$）|$872.7\text{ B/s}$（约 $0.85\text{ KB/s}$）|
|**19,200**|$1,920\text{ B/s}$（约 $1.88\text{ KB/s}$）|$1,745.5\text{ B/s}$（约 $1.70\text{ KB/s}$）|
|**115,200**|$11,520\text{ B/s}$（约 $11.25\text{ KB/s}$）|$10,472.7\text{ B/s}$（约 $10.23\text{ KB/s}$）|
|**921,600**|$92,160\text{ B/s}$（约 $90.00\text{ KB/s}$）|$83,781.8\text{ B/s}$（约 $81.82\text{ KB/s}$）|

### 5.2 时钟容差理论极限

异步通信中，相位误差会随传输位数的增加而逐位累积：
- **采样累积约束**：在 8N1 模式下，传输包含 10 个 bit。为确保在第 10 bit（停止位）中心点附近正确采样，末位的累积相位偏移量不得超过 $\pm 0.5$ 个 bit 周期。

- **时钟精度指标**：理论最大允许相对误差为 $\frac{\pm 0.5}{10} = \pm 5\%$。

- **工程安全标准**：扣除信号上升/下降沿迟滞及内部采样时钟抖动后，收发双端的**时钟漂移必须控制在 $\le \pm 2\%$ 以内**（建议优先选用外部石英晶振，避免使用温漂较大的片内 RC 振荡器）。

## 6. 通信协商要素清单

通信双方建立物理链路与软件配置时，必须严格对齐以下要素：
1. **波特率（Baud Rate）**：如 9600、115200、921600 等。
2. **数据位（Data Bits）**：5 / 6 / 7 / 8 / 9 bit（通常固定为 8）。
3. **校验方式（Parity）**：None (N) / Even (E) / Odd (O) / Mark (M) / Space (S)。
4. **停止位（Stop Bits）**：1 / 1.5 / 2 bit。
5. **传输字节序（Endianness）**：默认为 LSB First（低位在先）。
6. **流控策略（Flow Control）**：  
    - **None**：无流控。
    - **RTS/CTS**：硬件流控，使用专用引脚电平状态通知对方是否允许发送。
    - **XON/XOFF**：带内软件流控，通过向数据流中插入 `0x11`（恢复）与 `0x13`（暂停）控制传输节奏。
