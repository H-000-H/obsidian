# 🔗 UART 通信协议完整技术手册

> [!INFO] 笔记概览
> - **协议定位**：异步、全双工、无时钟线的串行通信，收发双方靠约定波特率自同步；协议层只规定帧格式，与物理电气标准（TTL/RS-232/RS-485）解耦。
> - **内容范围**：物理接线 · 电气标准 · 帧格式 · 奇偶校验 · 过采样抗干扰 · 硬件错误标志 · 配置模式 · 吞吐与时钟容差 · 流控
> - **推荐路径**：§1 物理层 → §2 帧格式 → §3 校验与容错 → §4 配置模式 → §5 吞吐/时钟误差 → §6 协商清单

## 🔌 1. 组成与物理特性

### 1.1 通信方式

| 属性 | 说明 |
| :--- | :--- |
| 定义 | UART（Universal Asynchronous Receiver/Transmitter，通用异步收发器） |
| 传输方式 | 异步串行通信 |
| 双工模式 | 通常全双工（可同时收发） |
| 时钟机制 | **无单独时钟线（CLK）**，收发双方依赖约定的**波特率**配合本地时钟自同步 |
| 基础信号线 | **TX**（发送）、**RX**（接收）、**GND**（参考地，双方必须共地） |

### 1.2 物理接线关系

收发双方的 TX 与 RX 必须**交叉连接**，GND 直连：

```text
MCU / 发送端                     PC / 接收端
┌─────────┐                     ┌─────────┐
│      TX ├────────────────────►│ RX      │
│      RX │◄────────────────────┤ TX      │
│     GND ├─────────────────────┤ GND     │
└─────────┘                     └─────────┘
```

> [!NOTE] 硬件流控接线
> 若启用硬件流控，RTS（Request to Send）与 CTS（Clear to Send）引脚同样需要**交叉互连**。

### 1.3 协议层与物理电气标准解耦

UART 仅规定数据链路层的帧格式与时序，不绑定特定物理电平。按传输距离与抗干扰要求，可配合不同收发芯片接入不同电气总线：

| 接口标准 | 逻辑 0 电平 | 逻辑 1 电平 | 电气形态 | 传输距离与特点 |
| :--- | :--- | :--- | :--- | :--- |
| **TTL / CMOS** | $0\text{ V}$（或 $\le 0.8\text{ V}$） | $V_{CC}$（$3.3\text{ V}/5\text{ V}$） | 单端（相对系统地） | 板级/近距离调试（$< 30\text{ cm}$） |
| **RS-232** | $+3 \sim +15\text{ V}$ | $-3 \sim -15\text{ V}$（负逻辑） | 单端（相对信号地） | 短距设备互连（$< 15\text{ m}$，$\le 115.2\text{ kbps}$） |
| **RS-485** | $V_A - V_B < -200\text{ mV}$ | $V_A - V_B > +200\text{ mV}$ | 差分信号对（A/B 双线） | 远距离工业现场总线（可达 $1200\text{ m}$，多节点） |

## 📦 2. 帧格式与传输时序

### 2.1 时序图

总线空闲（Idle）保持**高电平（Mark 状态）**，单字符完整时序：

```text
       Idle ──┐      ┌── D0 ─ D1 ─ D2 ─ D3 ─ D4 ─ D5 ─ D6 ─ D7 ─ [Parity] ─┐ ┌─ Idle
              │Start │                                                       │ │Stop
              └──────┘                                                       └──┘
Bit 状态:      逻辑 0            LSB 首发，MSB 尾发（常用 5~9 bit）           可选  逻辑 1 (1/1.5/2 bit)
```

### 2.2 字段构成

| 字段 | 长度 | 说明 |
| :--- | :--: | :--- |
| **空闲 (Idle)** | — | 持续高电平（逻辑 1） |
| **起始位 (Start)** | 1 bit | 固定低电平（逻辑 0），同步前导沿，唤醒接收器并重置位采样定时器 |
| **数据位 (Data)** | 5~9 bit（常用 8） | 有效载荷，默认 **LSB first**（低位在前） |
| **校验位 (Parity)** | 0 或 1 bit | 可选，单字节基础差错检测 |
| **停止位 (Stop)** | 1 / 1.5 / 2 bit | 固定高电平（逻辑 1），恢复线路并提供缓冲间隙 |

## 🛡️ 3. 校验逻辑与容错机制

### 3.1 奇偶校验生成规则

奇偶校验通过统计数据位中"1"的个数确定校验位电平：

| 校验类型 | 代号 | 判定规则 | 示例（0x53 = 0101 0011b，含 4 个"1"） |
| :--- | :--: | :--- | :--- |
| **无校验 (None)** | **N** | 帧中不含校验位 | 开销最小，常用于调试与高层带校验协议 |
| **偶校验 (Even)** | **E** | 数据位+校验位"1"总数为**偶数** | 4 个"1"已偶 → 校验位置 **0** |
| **奇校验 (Odd)** | **O** | 数据位+校验位"1"总数为**奇数** | 4 个"1"为偶 → 校验位置 **1**（凑成 5） |
| **标记校验 (Mark)** | **M** | 校验位恒置逻辑 **1** | 固定 1（多机主从的地址帧标记） |
| **空白校验 (Space)** | **S** | 校验位恒置逻辑 **0** | 固定 0（多机主从的数据帧标记） |

> [!WARNING] 奇偶校验的局限性
> 仅能发现**奇数个 bit 翻转**（1、3 个等）。若发生偶数个 bit 翻转，校验仍显示正常。高可靠场景需在应用层追加 CRC-16/32 或 CheckSum——Modbus RTU 即用 CRC-16，见 [[Modbus]]。

### 3.2 接收采样与抗干扰机制（Over-sampling）

由于没有共享时钟线，接收端采用本地高频倍频时钟（通常波特率的 **8× 或 16×**）动态重采样：

- **有效边沿捕获**：检测到 RX 下降沿后，延迟半个 bit 时间（如 16× 采样的第 7/8/9 个时钟脉冲）复测电平，仍为低才确认起始位有效，过滤瞬态毛刺。
- **多数表决判决**：每个 bit 周期中间区域连续采 3 个样本，"3 选 2"表决确定最终电平，避开边沿抖动。

### 3.3 硬件状态错误类型

| 标志 | 全称 | 触发原因 |
| :--: | :--- | :--- |
| **PE** | Parity Error（奇偶校验错误） | 数据位"1"个数与预设规则不符 |
| **FE** | Framing Error（帧错误） | 停止位时间窗内未检测到高电平（波特率不匹配 / 时钟严重漂移） |
| **OE** | Overrun Error（溢出错误） | 移位寄存器已满，CPU/DMA 未及时读走 RDR，旧数据被覆写 |
| **NE/NF** | Noise Error（噪声标志） | 单 bit 窗口内多次过采样值不一致，指示高频电磁干扰 |

## ⚙️ 4. 常见配置模式对照表

配置表示法通式：**数据位 + 校验方式 + 停止位**。

| 模式命名 | 起始位 | 数据位 | 校验位 | 停止位 | 帧总长 | 有效载荷占比 |
| :---: | :--: | :--: | :--: | :--: | :--: | :--: |
| **8N1**（工业最常用） | 1 | 8 | 0 | 1 | **10 bit** | 80.0% |
| **8E1** | 1 | 8 | 1 | 1 | **11 bit** | 72.7% |
| **8O1** | 1 | 8 | 1 | 1 | **11 bit** | 72.7% |
| **8N2** | 1 | 8 | 0 | 2 | **11 bit** | 72.7% |
| **7E1**（标准 ASCII） | 1 | 7 | 1 | 1 | **10 bit** | 70.0% |
| **7O1** | 1 | 7 | 1 | 1 | **10 bit** | 70.0% |
| **9N1**（多机通信） | 1 | 9 | 0 | 1 | **11 bit** | 81.8% |

## 📊 5. 波特率、数据吞吐量与时钟误差模型

### 5.1 理论吞吐率计算

常规 NRZ 编码下 $1\ \text{Baud} = 1\ \text{bit/s}$：

$$
\text{有效字符吞吐率 (Byte/s)} = \frac{\text{波特率}}{\text{每帧总 bit 数}}
$$

| 波特率 (Baud) | 8N1 吞吐 (Byte/s) | 8E1 / 8O1 / 8N2 吞吐 (Byte/s) |
| :--- | :--- | :--- |
| **9,600** | $960$（≈ 0.94 KB/s） | $872.7$（≈ 0.85 KB/s） |
| **19,200** | $1{,}920$（≈ 1.88 KB/s） | $1{,}745.5$（≈ 1.70 KB/s） |
| **115,200** | $11{,}520$（≈ 11.25 KB/s） | $10{,}472.7$（≈ 10.23 KB/s） |
| **921,600** | $92{,}160$（≈ 90.00 KB/s） | $83{,}781.8$（≈ 81.82 KB/s） |

### 5.2 时钟容差理论极限

异步通信中相位误差随传输位数逐位累积：

- **采样累积约束**：8N1 模式传输含 10 bit，为确保第 10 bit（停止位）中心点正确采样，末位累积相位偏移不得超过 $\pm 0.5$ bit 周期。
- **理论最大允许相对误差**：

$$
\frac{\pm 0.5}{10} = \pm 5\%
$$

> [!CAUTION] 工程安全标准
> 扣除信号上升/下降沿迟滞及内部采样时钟抖动后，收发双端**时钟漂移必须控制在 $\le \pm 2\%$ 以内**。建议优先选用外部石英晶振，避免温漂较大的片内 RC 振荡器。

## 📋 6. 通信协商要素清单

通信双方建立物理链路与软件配置时，必须严格对齐：

1. **波特率（Baud Rate）**：如 9600、115200、921600
2. **数据位（Data Bits）**：5 / 6 / 7 / 8 / 9 bit（通常 8）
3. **校验方式（Parity）**：None / Even / Odd / Mark / Space
4. **停止位（Stop Bits）**：1 / 1.5 / 2 bit
5. **传输字节序（Endianness）**：默认 LSB First
6. **流控策略（Flow Control）**：

| 流控 | 机制 |
| :--- | :--- |
| **None** | 无流控 |
| **RTS/CTS** | 硬件流控，专用引脚电平通知对方是否允许发送 |
| **XON/XOFF** | 带内软件流控，插入 `0x11`(恢复) / `0x13`(暂停) 控制节奏 |
