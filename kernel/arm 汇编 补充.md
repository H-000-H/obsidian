- **mrc** : 从 pc15 读出参数到通用寄存器
```
		mrc p15,0,r0,c1,c0,0
		读取 CP15 的`c1`（SCTLR 系统控制寄存器，MMU/Cache 开关）放到`r0`
```

- **mcr** : 从通用寄存器 写入 pc15
 ```
 mcr p15,0,r0,c1,c0,0
 把修改好的`r0`写回 CP15 的 SCTLR 寄存器
 ```
- tst : 位测试用来检查寄存器里**某一个 bit 有没有置 1**
	```
	如果`与运算结果≠0` → Z 标志 = 0
	如果`与运算结果=0` → Z 标志 = 1
	```
- orr : 按位或
```
orr r0, r0, #(1<<0)
r0 = r0 | 立即数
```
- bne 
```
bne label
搭配 TST：**如果检测的 bit 是 1，就跳转到 label**
> BNE：不为零就跳；BEQ 才是等于零跳转。
```
- adr r0 # x
```
根据pc计算出相对偏移x的地址存储到r0
```
- ldrb \res, \[\tmp1]
```
ldrb = Load Register Byte,从内存读1 字节到寄存器低
    8 位(高 24 位清零)。
   - [\tmp1] 表示以 \tmp1 寄存器的值作为内存地址。
   - 执行后:\res = *(uint8_t *)\tmp1。
```
- lsl 逻辑左移
```
r0 ,lsl #8
```
- 逻辑右移 
```
r0 , lsr #8
```
