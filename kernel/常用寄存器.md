# 🧮 ARM 常用寄存器速查（SCTLR 等）

> [!INFO] 笔记概览
> - **定位**：ARM32 启动与内核初始化路径上最关键的 CP15 系统控制寄存器（SCTLR）逐位语义速查，是理解 `head.S` MMU/Cache 开关的前提。
> - **内容范围**：SCTLR 关键位开关 · 补充寄存器使用注意
> - **推荐路径**：先读下方 SCTLR 位表 → 对照 `head.S` 中 `mcr`/`mrc` 读写场景使用。

---

## 🔧 1. SCTLR 系统控制寄存器（CP15 c1）

`mrc p15, 0, r0, c1, c0, 0` 读出，`mcr p15, 0, r0, c1, c0, 0` 写回。逐位语义：

| Bit | 名字 | 作用 |
| :--: | :--: | :--- |
| **bit0** | M | MMU 开关。1 = 开启 MMU（虚拟内存），0 = 关闭（物理地址直接访问） |
| **bit1** | A | 对齐检查开关 |
| **bit2** | C | D-Cache（数据缓存）开关 |
| **bit12** | I | I-Cache（指令缓存）开关 |
| **bit13** | V | 中断向量表基地址选择位 |

> [!TIP] 改动后必刷流水线
> 写回 SCTLR 后需 `isb`/`dsb` 冲刷流水线与内存屏障，确保 MMU/Cache 开关在后续指令生效前稳定。
