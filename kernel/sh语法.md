## 1. 脚本基础

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `#!/bin/sh` | shebang，声明解释器（须在第 1 行） | `#!/bin/bash` |
| `# 注释` | 单行注释 | `# 这是注释` |
| `: <<'EOF' ... EOF` | 多行注释（借 here-doc 空操作） | `: <<'COMMENT'` … `COMMENT` |
| `sh f.sh` | 用 sh 执行 | `sh build.sh` |
| `bash f.sh` | 用 bash 执行 | `bash run.sh` |
| `chmod +x f.sh` | 加执行权限 | `chmod +x deploy.sh` |
| `./f.sh` | 直接执行（需执行位） | `./deploy.sh` |
| `source f.sh` / `. f.sh` | **当前 shell** 内执行（共享变量/函数） | `. ~/.profile` |

> `./f.sh` 开子 shell，变量不回流；`source f.sh` 在当前 shell，变量会带上。

## 2. 变量

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `var=value` | 赋值，**`=` 两边不能有空格** | `name="tom"` |
| `$var` / `${var}` | 引用变量（`${}` 可界定边界） | `echo ${name}x` |
| `export var=value` | 导出为环境变量（子进程可见） | `export PATH="$PATH:/opt/bin"` |
| `readonly var` | 定义为只读 | `readonly PI=3.14` |
| `unset var` | 删除变量 | `unset tmp` |
| `local var` | 函数内局部变量 **(bash/多数 sh)** | `local i=0` |
| `declare -i/-a/-A` | 整型/索引数组/关联数组 **(bash)** | `declare -A map` |
| `var=$(cmd)` | 用命令输出赋值 | `now=$(date)` |

**默认值 / 条件展开（POSIX 也支持）：**

| 语法 | 说明 |
| --- | --- |
| `${var:-default}` | var 未设或为空 → 用默认值（不改变 var） |
| `${var:=default}` | 同上，但**会赋值给 var** |
| `${var:?msg}` | var 未设/空 → 打印 msg 并退出 |
| `${var:+alt}` | var 已设且非空 → 用 alt |

```sh
port=${PORT:-8080}          # 没设 PORT 就用 8080
: "${DB_URL:?DB_URL 未设置}"  # 没设就报错退出
```

## 3. 字符串操作

| 语法 | 说明 | 示例（`s="a/b/c.txt"`） |
| --- | --- | --- |
| `${#s}` | 长度 | `${#s}` → `9` |
| `${s#pat}` / `${s##pat}` | 删**最短/最长**前缀（`#` 短，`##` 长） | `${s#*/}` → `b/c.txt` |
| `${s%pat}` / `${s%%pat}` | 删**最短/最长**后缀 | `${s%.*}` → `a/b/c` |
| `${s/old/new}` | 替换**第一处** | `${s/\//-}` → `a-b/c.txt` |
| `${s//old/new}` | 替换**全部** | `${s//\//-}` → `a-b-c.txt` |
| `${s:off:len}` | 子串（0 起） | `${s:2:3}` → `b/c` |
| `${s^^}` / `${s,,}` | 全大写/全小写 **(bash 4+)** | `${s^^}` → `A/B/C.TXT` |
| `basename` / `dirname` | 取文件名 / 目录 | `basename "$s"` → `c.txt` |

> 记忆：**`#` 砍左边（前缀），`%` 砍右边（后缀）**；单符号=最短，双符号=最长。

## 4. 特殊变量

| 变量 | 含义 |
| --- | --- |
| `$0` | 脚本名 |
| `$1` … `$9` `${10}` | 第 N 个位置参数（≥10 要花括号） |
| `$#` | 位置参数个数 |
| `$@` | 所有参数，**逐个**独立（推荐） |
| `$*` | 所有参数，合成一个词 |
| `$?` | 上一条命令的退出码（0=成功） |
| `$$` | 当前 shell 的 PID |
| `$!` | 最近一个后台进程的 PID |
| `$_` | 上条命令的最后一个参数 |
| `shift` | 位置参数左移一位（`$2`→`$1`） |

```sh
echo "脚本=$0 参数个数=$# 全部=$@"
"$@"          # 正确：每个参数保留引号（推荐遍历用）
for arg in "$@"; do echo "[$arg]"; done
```

## 5. 引号与转义

| 写法 | 变量/替换 | 通配符 | 用途 |
| --- | --- | --- | --- |
| `'单引号'` | 全部字面 | 字面 | 原样字符串 |
| `"双引号"` | **展开** | 字面 | 含变量/命令替换 |
| `` `反引号` `` | 命令替换 | — | 老写法，改用 `$()` |
| `\` | 转义下一个字符 | — | `\"` `\$` `\\` |

```sh
name=tom
echo 'hi $name'   # hi $name
echo "hi $name"   # hi tom
echo "a\tb"       # a\tb（双引号里 \t 不转义，printf 才转）
```

> 铁律：**变量一律用双引号包起来** `"$var"`，否则含空格/通配符时会被拆分。

## 6. 算术运算

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `$(( 表达式 ))` | 算术求值 **(推荐)** | `echo $((1+2*3))` → `7` |
| `(( 表达式 ))` | 求值并按结果设置退出码 **(bash)** | `((i++))` |
| `$[ 表达式 ]` | 老式算术（已废弃） | `$[1+1]` |
| `let` | 计算并赋值 | `let i=i+1` |
| `expr` | 外部命令（慢） | `expr 1 + 2` |
| `bc` | 浮点运算 | `echo "1/3" \| bc -l` |

**运算符：** `+ - * / %`、`**`（幂）、`++ --`、`+= -= *= /= %=`、比较 `< <= > >= == !=`、逻辑 `&& || !`、位运算 `& | ^ ~ << >>`。

```sh
i=0; ((i+=1)); echo $i        # 1
n=$(( (1+2) * 3 )); echo $n   # 9
```

## 7. 命令替换 / 进程替换

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `$(cmd)` | 命令替换（推荐） | `files=$(ls)` |
| `` `cmd` `` | 命令替换（老，勿嵌套） | `` d=`date` `` |
| `<(cmd)` | 进程替换，当**文件**用 **(bash)** | `diff <(ls a) <(ls b)` |
| `>(cmd)` | 输出到命令 | `echo hi > >(cat)` |

## 8. 条件测试（test / [ ] / [[ ]]）

| 写法 | 说明 |
| --- | --- |
| `test 表达式` | POSIX 内建 |
| `[ 表达式 ]` | 同 test，**`[` 后、`]` 前必须有空格** |
| `[[ 表达式 ]]` | **bash 增强**：支持 `=~` 正则、`&&`/`\|\|`、无单词拆分 |

**文件测试：**

| 运算符 | 真条件 | 运算符 | 真条件 |
| --- | --- | --- | --- |
| `-e f` | 存在 | `-L f` | 是符号链接 |
| `-f f` | 是普通文件 | `-s f` | 存在且非空 |
| `-d f` | 是目录 | `-r f` | 可读 |
| `-w f` | 可写 | `-x f` | 可执行 |
| `f1 -nt f2` | f1 比 f2 新 | `f1 -ot f2` | f1 比 f2 旧 |

**字符串比较：**

| 运算符 | 真条件 |
| --- | --- |
| `s1 = s2` / `s1 == s2` | 相等（`==` 主要用在 `[[ ]]`） |
| `s1 != s2` | 不等 |
| `-z s` | 空串（长度为 0） |
| `-n s` | 非空 |
| `s1 < s2` | 字典序小于（`[[ ]]` 内） |
| `s =~ regex` | 正则匹配 **(bash `[[ ]]`)** |

**数值比较：**

| 运算符 | 含义 | 运算符 | 含义 |
| --- | --- | --- | --- |
| `-eq` | 等于 | `-gt` | 大于 |
| `-ne` | 不等于 | `-ge` | 大于等于 |
| `-lt` | 小于 | `-le` | 小于等于 |

```sh
[ "$a" -eq 10 ]            # 数值相等
[ -f /etc/passwd ]        # 文件存在
[ -z "$x" ] && echo empty  # 空串
[[ "$name" == *.txt ]]     # bash：通配匹配
[[ "$s" =~ ^[0-9]+$ ]]     # bash：正则
```

> `[ ]` 里数值比较**必须**用 `-eq/-lt`，不能用 `<`/`>`（会被当重定向）；字符串比较才用 `=`/`!=`。

## 9. 流程控制

**if / elif / else：**

```sh
if [ "$x" -gt 0 ]; then
    echo 正数
elif [ "$x" -lt 0 ]; then
    echo 负数
else
    echo 零
fi
```

**逻辑连接（短路）：**

| 语法 | 含义 |
| --- | --- |
| `cmd1 && cmd2` | cmd1 成功才跑 cmd2 |
| `cmd1 \|\| cmd2` | cmd1 失败才跑 cmd2 |
| `! cmd` | 取反 |

```sh
[ -d "$dir" ] || mkdir -p "$dir"
cd "$dst" && make
```

**case：**

```sh
case "$1" in
    start|up)   echo 启动 ;;
    stop|down)  echo 停止 ;;
    *.txt)      echo 文本文件 ;;
    *)          echo "用法: $0 {start|stop}" ;;
esac
```

## 10. 循环

**for：**

```sh
for f in *.txt; do echo "$f"; done          # 遍历通配
for i in 1 2 3; do echo $i; done             # 遍历列表
for ((i=0; i<10; i++)); do echo $i; done     # C 风格 (bash)
for x in $(seq 1 5); do echo $x; done        # 区间
```

**while / until：**

```sh
while read -r line; do echo "$line"; done < file   # 逐行读文件
while [ "$n" -lt 5 ]; do ((n++)); done
until [ -f /tmp/ready ]; do sleep 1; done           # 循环直到条件为真
```

**控制：**

| 语句 | 作用 |
| --- | --- |
| `break` | 跳出循环 |
| `continue` | 跳过本次，继续下一轮 |
| `break 2` / `continue 2` | 跳出/继续第 2 层循环 |

## 11. 函数

```sh
# 定义
greet() {
    local name="$1"          # local 局部变量
    echo "hello, $name"
    return 0                 # 返回状态码（0-255），不是返回值
}

# bash 备用写法
function greet { echo hi; }

greet "tom"                  # 调用
```

| 要点 | 说明 |
| --- | --- |
| `$1 $2 …` | 函数内取参数，同脚本位置参数 |
| `$#` `$@` | 参数个数 / 全部参数 |
| `local v` | 局部变量，避免污染全局 |
| `return N` | 返回**退出码**；要返回值用 `echo` + `$()` 捕获 |

```sh
add() { echo $(( $1 + $2 )); }
sum=$(add 3 4); echo "$sum"   # 7
```

## 12. 数组（bash）

| 语法 | 说明 |
| --- | --- |
| `arr=(a b c)` | 索引数组初始化 |
| `${arr[0]}` | 第 0 个元素 |
| `${arr[@]}` | 所有元素（逐个） |
| `${arr[*]}` | 所有元素（合一） |
| `${#arr[@]}` | 元素个数 |
| `${!arr[@]}` | 所有下标 |
| `arr+=(d)` | 追加元素 |
| `unset arr[1]` | 删除元素 |
| `declare -A m; m[k]=v` | 关联数组（哈希） |

```sh
fruits=(apple banana cherry)
echo "${fruits[1]}"          # banana
for f in "${fruits[@]}"; do echo "$f"; done

declare -A color
color[red]=#f00
echo "${color[red]}"         # #f00
```

## 13. 重定向

| 语法 | 说明 |
| --- | --- |
| `> file` | 覆盖写（stdout） |
| `>> file` | 追加写 |
| `< file` | 读入（stdin） |
| `2> file` | 错误输出（stderr） |
| `&> file` / `>file 2>&1` | stdout+stderr 一起 |
| `&>> file` | 一起追加 |
| `2>&1` | 把 stderr 并入 stdout |
| `> /dev/null 2>&1` | 丢弃全部输出 |
| `<<EOF … EOF` | here-doc（多行输入） |
| `<<< "str"` | here-string（喂字符串） **(bash)** |
| `n>&-` | 关闭 fd n |

```sh
cmd > out.log 2>&1                 # 日志+错误同一文件
ssh host <<'EOF'                   # 引号防变量本地展开
echo "hi"
EOF
read x <<< "hello"                 # here-string
```

> 顺序敏感：`2>&1 > f` 与 `> f 2>&1` 不同。**先 `>f` 再 `2>&1`** 才把两者都写进 f。

## 14. 管道与常用命令

| 语法/命令 | 说明 | 示例 |
| --- | --- | --- |
| `a \| b` | a 的 stdout 接到 b 的 stdin | `ps aux \| grep nginx` |

| `grep -rn` | 递归+行号搜索 | `grep -rn foo .` |
| `wc -l` | 统计行数 | `wc -l < file` |

## 16. 常用选项与陷阱

**脚本开头的"严格模式"（推荐）：**

```sh
#!/usr/bin/env bash
set -euo pipefail
# -e  任一命令失败即退出
# -u  引用未定义变量即报错
# -o pipefail  管道中任一环失败即视为失败
```

| 陷阱 | 正确做法 |
| --- | --- |
| `var = value`（有空格） | `var=value`（等号两侧无空格） |
| `[ $x = a ]` 变量为空报错 | `[ "$x" = a ]`（加引号） |
| `for f in $(ls)` | `for f in *`（避免按空格拆词） |
| `[ 1 < 2 ]` 被当重定向 | 数值用 `[ 1 -lt 2 ]`；`[[ 1 < 2 ]]` 才行 |
| `[[ ]]` 用于 `/bin/sh` | `[[ ]]` 是 bash 扩展；POSIX 用 `[ ]` |
| 忘记引号导致空格拆分 | 变量一律 `"$var"` |
| `cd` 失败仍继续 | `cd "$dir" \|\| exit 1` |
| 临时文件用固定名 | 用 `mktemp` |
| `rm -rf $dir/`（$dir 为空） | `rm -rf "${dir:?}/"` |

**调试：**

| 写法 | 作用 |
| --- | --- |
| `bash -x script.sh` | 打印每条执行命令 |
| `set -x` / `set +x` | 开/关追踪 |
| `set -n` | 语法检查（只解析不执行） |

## 备注
- `[ ]`：POSIX，可移植；`[[ ]]`：bash/ksh/zsh 增强。
- 变量引用**永远加双引号** `"$var"`，是最重要的一条习惯。
- `$()` 优于反引号；`printf` 优于 `echo`（可移植性）。
