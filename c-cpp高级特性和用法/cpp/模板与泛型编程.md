# 模板与泛型编程

全是标准 C++17 的最小示例，讲清"是什么、怎么用"。

## 1. 为什么需要模板：一份代码，类型随便换

想写"比较两个数谁大"，要支持 `int`、`float`、`double`。不写模板就得每种类型复制一份：

```cpp
bool max_int(int a, int b)   { return a > b; }
bool max_float(float a, float b) { return a > b; }
bool max_double(double a, double b) { return a > b; }
```

用模板，类型当作"参数"：

```cpp
template <typename T>
inline bool greater_than(const T& a, const T& b)
{
    return a > b;
}

bool r1 = greater_than(3, 5);        // T 自动推断为 int
bool r2 = greater_than(1.5, 2.5);    // T 自动推断为 double
```

要点：`typename T` 是类型占位符；编译期对用到的每种 T 各生成一份，运行期零额外开销。

## 2. 类模板：一个骨架，多套数据

```cpp
template <typename T>
class Box
{
public:
    void put(const T& v) { m_val = v; }
    T    get() const     { return m_val; }
private:
    T m_val{};
};

Box<int>    ib;            // 只能放 int
Box<string> sb;            // 只能放 string
```

`Box<int>` 和 `Box<string>` 是两套无关类型，互相不能赋值。

## 3. 非类型模板参数（NTTP）：常量也能当模板参数

除了类型，还能传整数/枚举，编译期就确定：

```cpp
template <typename T, int N>
class Array
{
public:
    int size() const { return N; }
private:
    T m_data[N]{};        // N 编译期已知, 可用来定数组大小
};

Array<int, 8>  a8;
Array<int, 16> a16;
```

要点：`N` 在编译期已知，所以能拿来定数组大小、做 `static_assert`。

## 4. CRTP：基类模板参数传"子类自己"

普通继承时基类不知道子类是谁；让基类名字里带子类，它就能在编译期"调用子类刚补全的东西"：

```cpp
template <typename Derived>
class Counter
{
public:
    int add(int x)
    {
        // 把 this 转回真正的子类来调
        return static_cast<Derived*>(this)->step(x);
    }
};

class Doubling : public Counter<Doubling>   // 子类把自己传给模板参数
{
public:
    int step(int x) { return x * 2; }       // 无 virtual, 无虚表开销
};
```

用途：比虚函数省 vtable、看一样直接内联，高性能/嵌入式场景好用；不同子类实例互不干扰。

## 5. 模板特化：给特定类型"开小灶"

```cpp
template <typename T>
string describe()
{
    return "generic";
}

template <>                       // 特化：针对 string 单独写
string describe<string>()
{
    return "a string!";
}

describe<int>();      // "generic"
describe<string>();   // "a string!"
```

理解：先写通用版，再为特殊类型覆盖。可配合 `static_assert` 当作"支持清单"。

## 6. `if constexpr`：编译期分支，不编译的另一边根本不存在

```cpp
#include <type_traits>
template <typename T>
void check(T value)
{
    if constexpr (std::is_pointer_v<T>)      // 编译期就知道真假
        std::cout << "它是指针\n";
    else
        std::cout << "它不是指针\n";
}
```

普通 `if` 两边都会编译；`if constexpr` 编译期只留一边，适合处理"同一函数的几种互斥组合"。

## 7. 完美转发 + 万能引用：参数原样接力

`T&&` 在模板里是万能引用（左值右值都能接），配合 `std::forward` 保持原值类别传下去：

```cpp
template <typename T>
void relay(T&& v)                     // 万能引用
{
    use(std::forward<T>(v));          // 保持 v 原本是左值还是右值
}
```

易错点：直接写 `v` 或 `std::move(v)` 会丢失调用方本来的值类别。

## 8. 小结

| 特性 | 一句话 |
| --- | --- |
| 函数模板 | 类型当参数，写一次 |
| 类模板 | 一个骨架，多套数据 |
| 非类型模板参数 | 常量也能当模板参数 |
| CRTP | 子类传给自己，无虚开销多态 |
| 模板特化 | 给个别类型开小灶 |
| `if constexpr` | 编译期选分支，另一侧不编译 |
| 完美转发 | 原样接力左值/右值 |
